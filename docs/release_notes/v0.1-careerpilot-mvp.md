# v0.1-careerpilot-mvp

CareerPilot Agent v0.1 is the first MVP release of a personalized job-search agent built on top of OpenHarness.

This release focuses on a complete, testable, and demo-ready job-search workflow: JD analysis, resume matching, project story extraction, interview preparation planning, application tracking, markdown skills, local memory, and OpenHarness dry-run validation.

## Added

- Added Career Coach Skill for the end-to-end job-search workflow.
- Added Resume Rewriter Skill for truthful and evidence-based resume tailoring.
- Added Interview Prep Skill for targeted interview study plans.
- Added JD Analyzer Tool for structured job description analysis.
- Added Resume Matcher Tool with explainable match scoring and gap analysis.
- Added Project Story Extractor for bilingual resume bullets and interview stories.
- Added Application Tracker using local JSON memory.
- Added Interview Plan Generator for 3-day or 7-day preparation plans.
- Added CareerPilot demo workflow through `careerpilot.demo`.
- Added OpenHarness adapter for lightweight workflow integration.
- Added English and Chinese README documentation.
- Added architecture, decision record, demo script, known issues, and development log documents.
- Added pytest coverage for core CareerPilot tools.

## MVP Scope

This release supports:

- JD requirement extraction
- Resume-to-JD match scoring
- Skill gap detection
- Resume keyword suggestions
- Project README to resume bullet conversion
- STAR-style interview story generation
- Interview preparation plan generation
- Local application status tracking
- End-to-end Markdown report generation
- Skill-guided OpenHarness workflow validation

## Known Limitations

- OpenHarness integration is currently lightweight and adapter-based.
- Native OpenHarness tool registry integration is planned for a later version.
- Matching score is heuristic and designed for explainability, not benchmarked accuracy.
- Resume suggestions require human review before real job submission.
- No RAG knowledge base is included in v0.1.
- No multi-agent workflow is included in v0.1.
- No IM gateway integration is included in v0.1.

## Suggested Demo Flow

1. Show the README and explain that CareerPilot is a job-search agent built on OpenHarness.
2. Show the input files: sample JD, sample resume, and sample project README.
3. Run the CareerPilot demo command.
4. Show the generated demo report.
5. Highlight match score, missing skills, rewritten project bullets, and interview plan.
6. Show the custom tools, markdown skills, local memory, and tests.
7. Run the test command and show all CareerPilot tests passing.
8. Run the OpenHarness dry-run command and show readiness is ready.
