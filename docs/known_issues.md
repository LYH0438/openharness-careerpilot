# CareerPilot Agent Known Issues

This document records current limitations of the CareerPilot Agent MVP and planned improvements.

The goal is to keep the project honest, maintainable, and easy to improve in the next phase.

## 1. OpenHarness Integration Is Still Lightweight

### Current state

CareerPilot currently integrates with OpenHarness through:

- Markdown skill files
- OpenHarness dry-run validation
- A lightweight adapter module
- A CLI-based demo workflow

### Limitation

CareerPilot tools are not yet registered as native OpenHarness tools in the OpenHarness tool registry.

The current integration shows alignment with OpenHarness concepts, but it does not yet represent full runtime tool invocation through the OpenHarness agent loop.

### Planned improvement

Add native OpenHarness tool registration or plugin integration in a later version.

## 2. Matching Score Is Heuristic

### Current state

The resume matching score is generated by deterministic matching logic.

It considers factors such as:

- Core skill coverage
- Missing skills
- Resume evidence
- JD responsibilities
- Interview focus areas

### Limitation

The score is useful for demo and explanation, but it is not benchmarked against real hiring outcomes.

It should not be interpreted as an objective probability of getting an interview.

### Planned improvement

Build a lightweight benchmark suite with multiple JD/resume pairs and evaluate:

- Keyword recall
- Missing skill precision
- Report completeness
- Schema validity
- Recommendation actionability

## 3. Deterministic Parser Has Limited Language Understanding

### Current state

CareerPilot uses deterministic parsing and rule-based extraction for stability.

### Limitation

This works well for predictable demo inputs, but it may miss subtle requirements in complex or unusual job descriptions.

For example, it may not fully understand:

- Implied seniority requirements
- Soft skill expectations
- Domain-specific business context
- Ambiguous wording
- Very long or poorly formatted job posts

### Planned improvement

Add an optional LLM-based analysis layer while keeping deterministic tools as schema validators and fallback logic.

## 4. Resume Suggestions Require Human Review

### Current state

CareerPilot generates resume bullets, rewrite suggestions, and interview stories.

### Limitation

Generated content may be incomplete, too generic, or too strong for the user's real experience.

CareerPilot should not be used to fabricate experience or exaggerate skills.

### Planned improvement

Add explicit safety policies and human-review reminders in generated reports.

## 5. Local JSON Memory Is Not Production Storage

### Current state

Application tracking is stored in:

    careerpilot/memory/applications.json

### Limitation

Local JSON storage is simple and inspectable, but it is not suitable for:

- Multiple users
- Concurrent writes
- Remote access
- Advanced filtering
- Long-term production use

### Planned improvement

Add optional SQLite or PostgreSQL storage if the project evolves beyond a local CLI MVP.

## 6. No RAG Knowledge Base Yet

### Current state

CareerPilot reads one resume file, one JD file, and one project description file in the demo workflow.

### Limitation

It does not yet retrieve from a larger personal knowledge base of:

- Multiple resume versions
- Multiple project documents
- Previous interview notes
- Past application outcomes
- Company-specific notes

### Planned improvement

Add a RAG-style knowledge layer for selecting the most relevant resume evidence and project stories for each job.

## 7. No Multi-Agent Workflow Yet

### Current state

CareerPilot is currently implemented as a single workflow with multiple tools.

### Limitation

It does not yet separate responsibilities into specialized agents.

### Planned improvement

Introduce specialized roles such as:

- JDAnalystAgent
- ResumeStrategistAgent
- ProjectStoryAgent
- InterviewCoachAgent
- ApplicationOpsAgent

Then aggregate their outputs into a final report.

## 8. No Chat or IM Channel Yet

### Current state

CareerPilot currently runs through local commands and demo scripts.

### Limitation

It cannot yet be used from Telegram, Slack, Feishu, Discord, or other chat interfaces.

### Planned improvement

Use ohmo or a similar gateway to expose the job-search workflow through a chat-based interface.

## 9. Demo Inputs Are Still Small

### Current state

The examples under `examples/careerpilot/` are intentionally small and easy to understand.

### Limitation

Small examples are good for learning and demos, but they do not fully test the system against messy real-world job descriptions and resumes.

### Planned improvement

Add more example cases and benchmark files covering:

- Backend roles
- AI agent roles
- ML engineer roles
- Platform engineer roles
- Junior and senior variants

## 10. Output Quality Still Needs Evaluation

### Current state

The output is readable and testable, but quality is mostly checked manually.

### Limitation

There is no automated quality metric for whether a resume bullet is strong, specific, and truthful.

### Planned improvement

Add evaluation checks for:

- Whether bullets include action, technology, and impact
- Whether suggestions are tied to JD gaps
- Whether unsafe exaggerations are avoided
- Whether interview plan tasks are specific and time-bounded
