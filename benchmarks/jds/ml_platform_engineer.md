# ML Platform Engineer

We are looking for an ML Platform Engineer to build infrastructure for model training, deployment, and monitoring.

Responsibilities:
- Build reliable ML pipelines for training and inference.
- Develop Python services for model deployment.
- Maintain data processing workflows and feature pipelines.
- Improve monitoring, testing, and reliability of ML systems.
- Work with cloud infrastructure and containerized environments.

Requirements:
- Strong Python and software engineering fundamentals.
- Experience with machine learning workflows.
- Familiarity with Docker, Kubernetes, and cloud platforms.
- Experience with CI/CD, monitoring, and production reliability.
- Understanding of data pipelines and model evaluation.
- Strong debugging and collaboration skills.
