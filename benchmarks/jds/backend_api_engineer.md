# Backend API Engineer

We are looking for a Backend API Engineer to design, build, and maintain scalable backend services.

Responsibilities:
- Design and implement RESTful APIs for customer-facing products.
- Build services using Python, FastAPI, and PostgreSQL.
- Improve API performance, reliability, and observability.
- Work with Docker-based development and deployment workflows.
- Collaborate with frontend and infrastructure teams.

Requirements:
- Strong Python programming experience.
- Experience with FastAPI, Flask, or similar backend frameworks.
- Solid understanding of relational databases and SQL.
- Experience with REST API design and authentication.
- Familiarity with Docker, CI/CD, and cloud deployment.
- Good communication and ownership.
