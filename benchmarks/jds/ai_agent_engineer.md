# AI Agent Engineer

We are hiring an AI Agent Engineer to build production-grade agent workflows for developer productivity and knowledge automation.

Responsibilities:
- Design agent workflows with tool use, memory, and structured outputs.
- Build Python services that integrate LLMs with external tools.
- Implement evaluation and tracing for agent behavior.
- Improve prompt reliability and reduce hallucination.
- Collaborate with product and infrastructure teams.

Requirements:
- Strong Python engineering skills.
- Experience with LLM applications, tool calling, and prompt engineering.
- Understanding of agent architecture, memory, permissions, and workflow orchestration.
- Experience with Pydantic or structured output validation.
- Familiarity with RAG, embeddings, or retrieval systems.
- Ability to write tests and evaluation pipelines.
